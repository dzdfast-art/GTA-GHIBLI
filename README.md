# GTA GHIBLI

An original third-person 3D open-world adventure for Android, built with Godot 4.

## Project status
**Early prototype.** The repository contains a basic procedural test scene with a player capsule, ground, lighting, camera, and simple touch movement controls. It has not yet been validated by running it in the Godot editor.

## Open the project
1. Install or open Godot 4.
2. Choose **Import** and select the repository folder.
3. Open `project.godot`.
4. Press **F6** to run the current scene, or **F5** to run the project.

## Creative direction
Create an original, warm, hand-painted fantasy atmosphere with exploration, characters, missions, and vehicles. GTA San Andreas may be used as a high-level genre reference only. Do not copy its maps, characters, dialogue, missions, branding, music, source code, or extracted assets.

## Important
The current mission and world files are design data. They are not yet connected to playable runtime systems. Features must be tested in Godot before being described as working.
