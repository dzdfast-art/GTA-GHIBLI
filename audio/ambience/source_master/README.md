# GTA GHIBLI — ambience source masters

This folder holds large editable/master audio sources under Git LFS. It is intentionally excluded from Godot's resource scanner by `.gdignore`, so the uncompressed production master is not copied into the Android APK.

The generated `willow_forest_day_master_07min.wav` is an original procedural soundscape: 7 minutes, 48 kHz, stereo, 24-bit PCM. It layers soft forest wind, foliage movement, distant stream texture and original bird chirps. It contains no speech or third-party recording. Use it as a source for editing and for making shorter, compressed runtime loops.
