# تجهيز أدوات فحص GTA GHIBLI (Godot 4.7)

هذه الإضافة التحضيرية لا تغيّر ملفات اللعب أو المشاهد أو الأصول. أُنشئت على فرع مستقل حتى تبقى `main` كما هي.

## الأدوات الثلاث

### 1) Godot Editor MCP — ربط مساعد التطوير بمحرر Godot

المصدر: https://github.com/hybridindie/godot-mcp

هذه الأداة تتكوّن من جزأين: إضافة داخل مشروع Godot، وخادم MCP يعمل على الكمبيوتر الذي يشغّل Godot. لذلك لا يكفي رفع ملفات إلى GitHub لتشغيل الاتصال؛ يجب تثبيت الخادم على الكمبيوتر نفسه.

**على كمبيوتر Windows / macOS / Linux:**

1. ثبّت Python 3.11 أو أحدث، وثبّت Godot 4.7.
2. افتح الطرفية وثبّت الخادم بالأمر:
   `python -m pip install --user godot-editor-mcp`
3. نزّل ملف `godot_mcp_addon.zip` من صفحة الإصدارات المستقرة:
   https://github.com/hybridindie/godot-mcp/releases
4. فك الضغط داخل مجلد المشروع بحيث يظهر المسار `addons/godot_mcp/`.
5. افتح المشروع في Godot، ثم اذهب إلى Project → Project Settings → Plugins.
6. فعّل Godot Editor MCP - Addon.
7. شغّل الخادم محلياً بالأمر `godot-editor-mcp`.

**تنبيه الاتصال:** تشغيل الخادم لا يعني أن هذه المحادثة اتصلت به. يلزم عميل MCP يدعم خادماً محلياً (stdio) وإعداد اتصال له. لا تلصق كلمات مرور أو مفاتيح وصول في GitHub أو المحادثة. لا تفتح منافذ الخادم للإنترنت. ابدأ بأدوات القراءة والفحص فقط، ولا تسمح بتعديل المشاهد أو السكربتات قبل مراجعة التغييرات.

الشرح الرسمي: https://hybridindie.github.io/godot-mcp/getting-started-install.html

### 2) GdUnit4 — اختبارات تلقائية داخل Godot

المصدر: https://github.com/godot-gdunit-labs/gdUnit4

1. افتح مشروع GTA GHIBLI في Godot 4.7.
2. افتح تبويب AssetLib.
3. ابحث عن GdUnit4.
4. ثبّت إصداراً متوافقاً مع Godot 4.7 (سلسلة 6.2.x أو أحدث إصدار يعلن صراحة دعم 4.7).
5. افتح Project → Project Settings → Plugins.
6. فعّل GdUnit4 ثم أعد تشغيل المحرر إن لزم.

بعد التثبيت، تُنشأ اختبارات منفصلة في مجلد `tests/`. لا تُعدّ الأداة مثبتة أو ناجحة حتى يظهر GdUnit4 Inspector وتُشغّل اختبارات فعلية. لا توجد اختبارات لعب مضافة تلقائياً في هذه الخطوة.

دليل التثبيت: https://godot-gdunit-labs.github.io/gdUnit4/latest/first_steps/install/

### 3) GDScript Toolkit (gdtoolkit) — فحص أسلوب وجودة السكربتات

المصدر: https://github.com/Scony/godot-gdscript-toolkit

تُشغّل هذه الأداة آلياً في GitHub Actions بواسطة الملف:
`.github/workflows/gdscript-lint.yml`

وهي تفحص تنسيق وقواعد كتابة GDScript. لا تثبت وحدها أن منطق اللعبة صحيح، ولا تستبدل تشغيل Godot أو اختبارات GdUnit4.

أوامر التشغيل المحلي بعد تثبيت Python:
```bash
python -m pip install --user gdtoolkit
gdlint scripts
```

## ماذا أُضيف إلى المستودع؟

- سير عمل GitHub Actions لتشغيل gdlint على ملفات GDScript المتتبعة.
- هذا الدليل العربي لتثبيت الأدوات الثلاث والتحقق منها.

## ما الذي لم يحدث بعد؟

- لم يتم تثبيت أي برنامج على هاتفك أو حاسوبك.
- لم يتم إدخال إضافة MCP إلى ملفات المشروع من هذه الخطوة؛ لأنها تحتاج إلى تنزيل إصدارها المطابق وفكّه داخل نسخة المشروع المحلية.
- لم يتم تثبيت GdUnit4 داخل المشروع بعد.
- لم يتم إجراء أي تعديل على مشاهد اللعبة أو السكربتات أو الأصول.
- لا يعني نجاح فحص lint أن اللعبة تعمل أو أن APK صالح.

## طريقة المراجعة الآمنة

1. راجع هذا الفرع والملفات المضافة.
2. راجع نتيجة GitHub Actions.
3. ثبّت الإضافات محلياً بعد أخذ نسخة احتياطية.
4. شغّل الاختبارات وسجّل النتائج.
5. لا تدمج الفرع إلى main قبل مراجعة نتائج الفحص والموافقة.
