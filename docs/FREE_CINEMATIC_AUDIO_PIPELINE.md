# مسار الصوت السينمائي المجاني — GTA GHIBLI

## الهدف والقيود

- الميزانية: صفر؛ لا اشتراكات ولا خدمات توليد مدفوعة ولا أصول مدفوعة.
- الأولوية الأولى: أداء تمثيلي عربي حيّ ومقنع، مع ثبات هوية صوت كل شخصية.
- الرسومات الحالية وأصول العالم والإضاءة والخامات والكاميرا لا تُحذف ولا تُخفّض الجودة من أجل إضافة الصوت.
- لا تُضمّن أوزان نماذج الذكاء الاصطناعي الكبيرة داخل APK. تُستخدم خارج اللعبة لإنتاج ملفات صوت نهائية، ثم تُستورد ملفات WAV/OGG المرخّصة فقط.
- لا ننسخ أصوات أو موسيقى أو ملفات أو شيفرات Rockstar؛ نستفيد من مبادئ تصميم الصوت السينمائي فقط.

## المستودعات والنماذج المرشحة

### 1. KasbahTTS — الخيار الأول للدارجة الجزائرية
- الصفحة: https://huggingface.co/Voice213/KasbahTTS-V0
- المستودع: https://github.com/Voice213/KasbahTTS
- الترخيص المعلن للأوزان: MIT.
- مخصص للدارجة الجزائرية، ويدعم توليد الكلام مع مرجع صوتي لاستنساخ طبقة الصوت.
- حجم ملف النموذج الأساسي المعروض: نحو 1.35 GB، لذلك لا يوضع داخل APK.
- لا يعلن عن متجه تحكم عاطفي مستقل؛ يجب اختبار نقل الانفعال من عينة الأداء المرجعية، ولا نعدّ المشاعر مضمونة قبل الاستماع.

### 2. SILMA TTS — بديل للفصحى
- النموذج: https://huggingface.co/silma-ai/silma-tts
- الشيفرة: https://github.com/SILMA-AI/silma-tts
- الترخيص المعلن: MIT للشيفرة وApache-2.0 للأوزان.
- يدعم العربية والإنجليزية واستنساخ الصوت؛ يستخدم للفصحى عند الحاجة.
- لا يُفترض أنه يوفر تحكماً عاطفياً دقيقاً ما لم يثبت ذلك في اختبار صوتي.

### 3. IndexTTS-2.5 — مرشح بحثي للتحكم العاطفي، وليس اعتماداً حالياً
- الشيفرة: https://github.com/index-tts/index-tts
- النموذج: https://huggingface.co/IndexTeam/IndexTTS-2.5
- يذكر دعم العربية والتحكم بمتجهات مشاعر (فرح، غضب، حزن، خوف، اشمئزاز، كآبة، دهشة، هدوء).
- يتطلب بحسب بطاقة النموذج Python 3.10–3.11 وGPU NVIDIA بذاكرة تقارب 6 GB VRAM.
- بطاقة النموذج تعرض ترخيص استخدام خاصاً (Bilibili Model Use License Agreement)، وليس MIT/Apache صريحاً؛ لذلك لا يُستخدم في إصدار اللعبة أو أي توزيع تجاري قبل مراجعة الترخيص والموافقة على ملاءمته. لا يُنزّل ولا يُدمج الآن.

## خطة الأداء العاطفي

لكل شخصية ملف صوت ثابت وعينة مرجعية مأذون باستخدامها. ولكل جملة:
1. تحديد النية الدرامية والسياق قبل اختيار الانفعال.
2. كتابة توجيه أداء عربي للممثل/النموذج: طبقة الصوت، سرعة الكلام، النفس، الوقفات، التردد، شدة الصوت.
3. توليد عدة محاولات ومراجعتها سمعياً؛ رفض النطق الآلي أو التكرار أو تشويه اللهجة.
4. اعتماد ملف واحد بعد اجتياز مراجعة النطق والانفعال وثبات هوية الشخصية.
5. مزامنة توقيت الصوت مع حركة الفم والإيماءات وردود فعل الشخصيات.

الانفعالات المطلوبة: فرح، حزن، خوف، غضب، دهشة، حنان، شك، ارتياح، ألم، توتر. لا يكفي تغيير pitch أو volume لإنتاج تمثيل حقيقي.

## التكامل السينمائي داخل Godot

- الحوار على ناقل صوت مستقل مع خفض الموسيقى تلقائياً أثناء الكلام (ducking).
- مؤثرات قريبة ثلاثية الأبعاد، وبيئة محيطية متكيفة مع المكان والطقس والوقت.
- لقطات سينمائية: تغيير مدروس للعدسات/المسافة/زاوية الكاميرا، حركة كاميرا ناعمة، ولقطات رد الفعل بعد الجمل المهمة.
- مزامنة الشفاه والتعابير والإيماءات مع الجملة والانفعال؛ لا تُفعّل حركة عشوائية موحدة لكل الشخصيات.
- إبقاء تحكم اللاعب باللمس مستقراً وإتاحة تخطي المشهد.
- حفظ جودة الرسومات والأصول الحالية؛ لا يتم استبدال الخامات أو تقليل الدقة أو تغيير إعدادات العرض كحل صوتي.

## بوابة الجودة قبل الدمج

لا تُعتبر الدبلجة منجزة حتى:
- توجد ملفات صوت محلية فعلية لكل جملة مستهدفة، لا روابط توليد عن بعد فقط.
- تُراجع اللهجة والنطق والوقفات والانفعال وثبات الصوت.
- تعمل الملفات دون إنترنت بعد تضمينها في اللعبة.
- ينجح فحص Godot وبناء APK.
- يُختبر الأداء على هاتف Android فعلياً، مع قياس الذاكرة وحجم APK.

## الحالة الحالية

هذه الوثيقة تربط المشروع بمراجع النماذج وتحدد مساراً مجانياً آمناً. لم يتم بعد تنزيل الأوزان أو توليد دبلجة جديدة أو إدخال ملفات صوتية جديدة. ملفات الصوت الإجرائية الموجودة حالياً تظل نموذجاً أولياً، وبيانات توجيه المشاعر ليست بديلاً عن الأداء الصوتي المسجل.
