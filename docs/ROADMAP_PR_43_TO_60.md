# خطة تطوير GTA GHIBLI من PR #43 إلى PR #60

هذه خارطة الطريق المعتمدة للمراحل القادمة، ويُنفّذ كل طلب سحب على حدة مع اختبارات ودليل تحقق قبل اعتباره منجزاً.

## PR #43 — قيود الانعطاف عند التقاطعات
إضافة قواعد الانعطاف المسموح والممنوع عند التقاطعات، والتحقق منها باختبارات للمسارات.

## PR #44 — توسيع شبكة الشوارع
توسيع شبكة الطرق داخل العالم وربط الشوارع والتقاطعات ونقاط الاهتمام بشبكة قابلة للملاحة.

## PR #45 — تحسين GPS والخريطة
تحسين حساب المسارات وإعادة التوجيه وعرض المسار والتعليمات والخريطة المصغرة.

## PR #46–#50 — المركبات والقيادة والطرق
تطوير المركبات وأنظمة القيادة والتحكم والفيزياء والتفاعل مع الطرق، مع اختبارات لكل ميزة.

## PR #51–#55 — العالم والشخصيات والأنشطة
توسيع العالم وإضافة الشخصيات وسلوكياتها والأنشطة والتفاعلات والمهام الجانبية.

## PR #56–#60 — تحسينات اللعب والاختبارات والتكامل
تحسين تجربة اللعب والاستقرار والأداء، وإصلاح الأخطاء، وإجراء اختبارات التكامل والتحقق من توافق الأنظمة.

## قواعد التنفيذ والتحقق
- هذه الخطة تحدد العمل المستقبلي ولا تعني أن الميزات قد نُفذت بالفعل.
- يُنفّذ كل PR في فرع مستقل ويُراجع قبل الدمج.
- لا يُعتبر أي PR مكتملاً إلا بعد فحص التغييرات الفعلية ونجاح الاختبارات المناسبة وتوثيق النتائج.
- تُحافظ المراحل على الميزات السابقة ولا تستخدم ملفات حشو لزيادة حجم المشروع.
- لا يُدمج أي PR تلقائياً؛ قرار الدمج النهائي لصاحب المشروع.
